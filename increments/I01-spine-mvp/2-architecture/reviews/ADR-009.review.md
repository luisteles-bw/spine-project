## Summary
ADR-009 faithfully records the Topic-9 decision (S01:46, S01:79-80) and its 2026-11-23 amendment, and
every external claim I checked (git `--trailer` floor, `gh repo edit` merge flags, `gh pr view --json`
fields, `merge-base --is-ancestor` semantics, GitHub Free having no branch protection for private
repos) is true today. The findings are impact gaps, not fidelity errors: the ADR claims to cover
REQ-043 but never addresses the PR body that REQ-043's acceptance criterion requires, and one
session-log open point plus the ADR's own `refs` are now stale against the amendment.

## Areas with no findings
- Fidelity of the core Topic-9 decision: arg-array git, `core.hooksPath=/dev/null` + `core.fsmonitor=false`, `LC_ALL=C`, `GIT_TERMINAL_PROMPT=0`, porcelain/`-z` parsing, explicit staging (no `add -A`), `--trailer` trailers + `Spine-Seq`, slug validation, `code/.git` denyWrite from switch-over, agents read-only git with `GIT_OPTIONAL_LOCKS=0`, git ≥ 2.32 floor, `gh` CLI for PR/merge, `spine pr`→ask, push phase-branches-only / never `--force`, merge-commit-only, tamper-proof `phase_pr` via SHA + `merge-base --is-ancestor` — all match S01:46 and S01:79-80.
- External facts verified: `git commit --trailer` is documented in 2.32.0 (git-scm.com/docs/git-commit/2.32.0), so the ≥ 2.32 floor is correct. `gh repo edit --enable-squash-merge=false --enable-rebase-merge=false` are real flags (cli.github.com/manual/gh_repo_edit). `gh pr view --json` supports `state`, `mergedAt`, `mergeCommit` (cli.github.com/manual/gh_pr_view). `git merge-base --is-ancestor` exits 0/1/128 as relied on (git-scm.com/docs/git-merge-base). GitHub Free has no branch protection/rulesets for private repos (GitHub Docs / community discussions).
- Amendment fidelity: the 2026-11-23 amendment (spine pr ask = baseline; branch protection conditional on plan; phase numbers removed; visibility → internal) matches the plan (`spine pr`→ask baseline P02, `plan.md:133`) and the "phase numbers live in the plan" convention (ADR→phase table, `plan.md:60`). `version: 2`, `updated: 2026-11-23` and `visibility: internal` are consistent with the log (STATE.md:50).
- Consistency with ADR-006/ADR-012: `code/.git` joining `denyWrite` at switch-over matches `plan.md:141`; SEC-016 (ADR-009) hooks-off attribution matches `security.md:71`.
