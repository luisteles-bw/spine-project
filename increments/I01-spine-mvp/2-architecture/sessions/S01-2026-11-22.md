## Decisions
| # | Topic | Decision | ADR |
| --- | --- | --- | --- |
| 1 | Packaging & run model | Single workspace-ready package; core compile-isolated via its own tsconfig (`types: []`) + ESLint bans on `Date.now`/argless `new Date()`/`Math.random`; stable `spine` from a `pnpm pack` tarball of the last merged phase, `spine-dev` alias for the working copy, `pnpm spine <cmd>` until switch-over; versions `0.1.0-dev.N`. | ADR-001 |
| 2 | Toolchain | Node 24 LTS, ESM; TS strict + `erasableSyntaxOnly` + `verbatimModuleSyntax`; build with **tsdown** (pinned, bundled for fast guard); **ESLint + Prettier** (type-aware rules, `no-floating-promises`, import boundary); **tsx** dev loop, migration-ready to native type stripping; Vitest. | ADR-002 |
| 3 | CLI contract | **commander** (pin v15) in routing-only mode (`.exitOverride()`/`.configureOutput()`, usage errors → exit 2); core schemas validate values. `--json` = one JSON doc on stdout for every outcome (incl. crash `INTERNAL`), logs on stderr; uniform envelope `{ok,command,data?,error?}`; `error.code` from a fixed core list → exit via one table (ok 0/refused 1/invalid 2/env+internal 3). Guard ships as its own bin. `--json` contract test per command. | ADR-003 |
| 4 | Schemas | **Zod-first (Zod 4, pinned)**; dates as strings (`z.iso.*`); frontmatter = strict discriminated union on `type`; additive-only from switch-over + one migration pass for bootstrap docs. JSON Schema **generated, committed under `schemas/`, diff-checked**; `unrepresentable:"throw"`; Ajv (dev, `dist/2020`) contract test; refinements rare + registered. | ADR-004 |
| 5 | Documents | **`yaml` (eemeli) + tiny splitter** (1.2/core/uniqueKeys/strict; BOM+CRLF; gray-matter rejected for date coercion + `eval` of `---js`); in-place `parseDocument` edits; `version` integer. Required headings via **line scan** (skip fences; per-type registry beside schema; template-only = empty = fail). **id index rebuilt per command** (`project/` only, code-unit sort, dup=error, frontmatter refs only, dangling warns on drafts / blocks at gates). **graph.json write-only**; guard never indexes. | ADR-005 |
| 6 | Event log & state | `events.jsonl` sole source of truth; event `{seq,ts,type,node,actor,payload}`, **seq = line position** (gap/dup = hard stop), types additive-only, `actor` from shell detection not a flag. **graph.json** = pure deterministic reducer, no timestamp. Integrity: per-record SHA-256 (raw bytes at submit) in its event + `project/` git; records never edited, every gate re-checks hashes. **Only-spine-writes** enforced by human-applied sandbox/settings denies + `excludedCommands:["spine *"]` + `allowUnsandboxedCommands:false` at switch-over. **Hand-rolled `O_EXCL` lock** (stale = dead pid via `kill(pid,0)`; short critical section; re-read seq under lock). Torn **final** line = human-only repair; interior corruption = hard stop. One-machine; cross-machine = git conflict. | ADR-006 |
| 7 | Lifecycles & gates | **Typed transition tables + one generic pure reducer**; guards = named pure fns; tests enumerate the full state×event product; docs diagrams generated from tables; **every state change has an event** (limit trips append explicit events). **Gate tags in code; config scopes, never disables** by track/profile; **approval bound to SHA of the approved doc** (edit → gate reopens); `phase_pr` via GitHub merge (records PR#/base/merge SHA), others via `approve`. Six stages fixed-order in code, **track may only omit**; **track+gates+limits snapshotted into the increment-creation event** (reducer reads from event, not live `spine.yaml`) → REQ-010 stable; config changes new increments only, running change via CR. `spine.yaml` write-protected like state. | ADR-007 |
| 8 | Context assembly | `spine context <id>` = **deterministic path list** (entry: `path`, `reason`, `bytes`, `range` for in-doc ids, `trusted:false` for client docs); recipe table shared with `next`. **Slices not whole files** (id index gains line ranges, extends ADR-005); latest verify = highest attempt in the **event log**; list is read-first, not a read-scope (guard owns that); **attempt-start event snapshots the list + content hashes**. Size = **soft byte warning** (~100 KB / ~25k tok, slices only, returned in `data`) **plus a plan-time budget check** listing over-budget tasks at the plan gate. | ADR-008 |
| 9 | Git & PR | **Shell out to real `git`** (`execFile`, arg arrays, SEC-009); every call `-c core.hooksPath=/dev/null -c core.fsmonitor=false` (never run working-tree hooks outside the sandbox), `LC_ALL=C`, `GIT_TERMINAL_PROMPT=0`, porcelain/`-z` parsing; **explicit path staging** (never `add -A`; out-of-scope → submit refuses); trailers via `--trailer` (+ `Spine-Seq:<n>` on `project/` commits); slug validation; git ≥2.32 (else exit 3); `code/.git` denyWrite from switch-over; agents read-only git (`GIT_OPTIONAL_LOCKS=0`). **`gh` CLI** for PRs/merge; **`spine pr` → `ask`** (internal git/gh bypass ask rules); push phase branches only, never `--force`; **merge-commit only** (disable squash/rebase on repo create); **`phase_pr` counts only if head SHA == review-approved SHA and is ancestor of base** (`merge-base --is-ancestor`). | ADR-009 |
| 10 | Guard hook | **One global PreToolUse hook**; role = hook input **`agent_type`** (none = main session; unknown = **read-only**) — replaces spec's per-agent `--role`. Reads tiny **`active.json`** `{seq,role,node,attempt,scope,testFiles}` written **inside the ADR-006 lock** with the event seq; **realpath** scope match; **every tool matched, unknown tools denied** for scoped roles. Bash = **per-role allowlist of shapes** (tripwire): deny `$(…)`/backticks/`eval`/`-c`-`-e`/file-redirection/unparseable; writes only via Edit/Write. **Fail closed**: `spine-guard || exit 2` (CC blocks only on exit 2), own short deadline, never spawns, `tool_input` untrusted; no off switch (roll back tarball); deny Edit/Write on `~/.claude/**`. Real controls = sandbox + submit-time scope diff + test-file hashes at "Tests ready". | ADR-010 |
| 11 | Checks & secrets | **Spine wraps each check with `@anthropic-ai/sandbox-runtime`** (pinned; CC's sandbox; `new_dependency` gate); **network deny-by-default + per-check profile allowlist**; **least-privilege secrets per check** (`test` none, `build` only CMS token); **post-check sweep** of changed+untracked files for injected values (hit = fail); test asserts keychain unreadable inside the sandbox. Commands = **argv arrays via `execFile` calling tools directly** (`pnpm exec vitest/eslint/tsc`), **never package.json scripts** (coder-editable); check configs **default-forbidden** to coders; Vitest JSON reporter; submit needs a passing `AC-n` test per criterion. Keychain `security`/`secret-tool` (WSL → 0600 file + denyRead), inject into child only, Bash-deny `security`/`secret-tool`. Redaction = exact values **+ base64/URL forms**, full output before summarise, refuse <8-char secrets. | ADR-011 |
| 12 | Admin boundary & settings | **OS-enforced, not env/TTY** (both spoofable): human-only cmds (`approve`,`reject`,`phase cut`,`repair`,`init`,`upgrade`) live in a separate **`spine-admin`** binary **not in `excludedCommands`** → an agent running it is **sandboxed → `denyWrite` blocks it**; human runs it outside CC. Main `spine` has no admin code; `spine-guard` separate → **three bins**. Settings: `allowUnsandboxedCommands:false`, **`failIfUnavailable:true`**, `excludedCommands:["spine *"]`, `denyWrite` state/git **+ mirror of every Edit/Write deny**, `denyRead` `.env*`+home creds (`sandbox.credentials` masks tokens); allow `spine *`, ask `spine pr *`/WebFetch, deny `spine-admin *`+**`gh *`**+git-writes+keychain+`.claude`/`~/.claude`/`spine.yaml`; `disableBypassPermissionsMode`/`disableAutoMode:"disable"`; one global `spine-guard || exit 2` (added only after guard exists); `GIT_OPTIONAL_LOCKS=0`. Templates from installed package (not `code/claude/`) + diff. **Phased**: baseline now, state/git denies at switch-over. | ADR-012 |
| 13 | Profiles & init | Profiles are **data, shipped in the package** (not workspace); contract = **declarative overlay** (JSON key-merge; **code files replaced whole**); ships a smoke test (no `--passWithNoTests`); keep CNA's CLAUDE/AGENTS but **write-protect `code/CLAUDE.md`+`code/AGENTS.md`**; set `NEXT_TELEMETRY_DISABLED=1`, `experimental.agentFeedback:false`. Scaffolder: `create-next-app@latest --disable-git --skip-install` **sandboxed** (npm allowlist) → overlay → **`pnpm install` sandboxed** (build scripts off; profile `allowBuilds` via `new_dependency` gate); **pnpm ≥10.26**; **atomic** temp-dir, move in only after the 4 checks pass; record CNA/Node/pnpm/lockfile-hash in the project's ADR-001. **MCP**: official-only + **write-protected**; **stdio servers pinned exact (no `@latest`)**; nextjs-static default = **next-devtools + Context7** (**Vercel deferred** until hosting; project-specific URL when linked). Checks = direct tools; versions frozen per increment. | ADR-013 |
| 14 | Twenty app & sync | **Twenty 2.0 app SDK** (brief's SDK-risk note predates 2.0) — objects/fields on standard objects/relations/views with stable ids; **each sync enforces declared state** (REQ-070). Pin **Docker image + `twenty-sdk` together**; **generate defs from `taxonomy.json`**; **P08 half-day spike first**, metadata-API fallback only if it fails; **additive-only** (field removal = backup + CR). Sync = **one-way REST**, **outbox on the event log** (replay from last synced `seq`; never blocks a transition); unique **`spineId`** per owned record, `crm-ids.json` a **cache** (miss/404 → look up by `spineId` before create → no dups). **Ownership split**: spine owns/overwrites its objects, **never writes Opportunity/Company/Person** (links only). Markdown rich text; whitelisted fields + `visibility` (SEC-013); throttle/backoff. Twenty reads = **`trusted:false`**; API key in keychain. | ADR-014 |
| 15 | Testing strategy | Four layers: **unit** (`*.test.ts`, pure core, injected clock/ids, full state×event product, replay-stability) · **integration** (`tests/`, temp dirs + real git) · **contract** (`--json` envelope, Ajv schema) · **e2e** (fixture `init`→merged PR, golden log + graph). E2E: **fake `gh` at the PATH boundary** (stub records argv, returns recorded real `gh pr view` JSON), **bare-repo** remote, asserts **ADR-009 refusals** (squash / post-review push → `phase_pr` unsatisfied); **git isolation** (`GIT_CONFIG_GLOBAL=/dev/null`, `GIT_CONFIG_NOSYSTEM=1`, fixed author/date); **events store workspace-relative paths only**; guard tests feed recorded PreToolUse incl. a **simulated crash** (prove `|| exit 2`). Twenty: **stateful fake** (sync-twice / deleted `crm-ids.json` / record deleted in Twenty → no dups, REQ-071); fixtures from throwaway Twenty, **version-stamped**; real check = manual `pnpm test:twenty` (local Docker, not CI). CI = macOS+Linux/Node 24, **under sandbox + network denied** (proves REQ-084). **Quality red-team checklist** (known bypasses must all fail → record). Optional `fast-check` reducer property test. | ADR-015 |
| 16 | Switch-over | **Genesis event sequence** (discrete events STATE.md justifies, `source: bootstrap-import`, original dates/actors) — **migrate docs (ADR-004) first**, then **`spine-admin import --dry-run`** (prints events + status diff), **re-confirm each imported approval against the doc's current hash** (ADR-007), **hash all records** (immutability starts here, ADR-006); "matches" = **normalized projection** (statuses/gates), not text. **Cutover checklist with rollback**: 1 tag both repos (human) · 2 install tarball · 3 migrate · 4 import+verify · 5 apply phase-2 settings + guard hook (now `spine-guard` exists) · 6 **restart CC** · 7 red-team · 8 archive. Rollback = restore tags + prior settings, kept until first post-switch phase merges. Archive bootstrap as **`STATE.bootstrap.md`**; `/approve`·`/reject` → **stubs** → `spine-admin approve`; status/next/architecture → real spine; CLAUDE.md + agent files from **package templates** (`spine-admin upgrade`); **check fails if any agent doc still says edit STATE.md**. | ADR-016 |
| 17 | OS support & preflight | **Tiers**: macOS = **tier 1** (daily, red-team verified; security guarantees claimed **only here**); Linux + WSL2 = **tier 2** (CI-tested, not yet red-teamed); **native Windows unsupported** (WSL2 = Linux paths). WSL2 (preflight-enforced): workspace on Linux FS (`~/…`), **refuse `/mnt/*` + WSL1**; CC must run in the WSL remote. **Per-command preflight** (declares only the tools it needs; missing → exit 3 + remediation); **guard never preflights**. **`spine doctor`** audits hardening (settings vs template; `sandbox.enabled`/`failIfUnavailable`/`allowUnsandboxedCommands:false`; guard hook present; no weakening `settings.local.json`/user override). **Post-switch-over, state-changing commands refuse (exit 3) if sandbox or guard hook is off.** | ADR-017 |

## Questions and answers
<!-- Short. Question, options offered, the answer given, who answered. -->
- **T1 structure.** Offered A single workspace-ready package / B full monorepo / C single no workspace. Chose **A** with four refinements (core tsconfig `types:[]`; ESLint bans clock/random in core; twenty-app joins the workspace at P08 only if Twenty's tooling allows; escape hatch to promote core to its own package if violations recur). — human.
- **T1 install.** Nothing global until switch-over (`pnpm spine <cmd>`). After switch-over: global `spine` = tarball of last merged phase (keep 2–3 for rollback); working copy = `spine-dev` alias; guard always calls the stable `spine`; versions `0.1.0-dev.N`, `0.1.0` at P11; no private registry yet. — human.
- **T2 build.** Offered tsdown / tsup / tsc. Chose **tsdown** (tsup is now unmaintained and points to tsdown; bundling keeps the guard fast). Pin the version. — human.
- **T2 lint.** Offered ESLint+Prettier / Biome. Chose **ESLint + Prettier** — reason corrected to typescript-eslint's type-aware rules (`no-floating-promises` for event-log writes) + the core→adapter import boundary; Biome 2 could ban `new Date()` via GritQL, so that was not the deciding factor. — human.
- **T2 dev run.** Offered tsx / Node native strip-types / built JS. Chose **tsx**, and enable `erasableSyntaxOnly` + `verbatimModuleSyntax` now so we can switch to Node 24 native stripping and drop tsx later. — human.
- **T3 parser.** Offered commander / citty / util.parseArgs. Chose **commander** (pin v15, ESM-only). citty is 0.x; tsdown bundles any parser so ecosystem alignment gains nothing. `.exitOverride()`+`.configureOutput()` so commander never prints/exits; usage errors → our renderer, exit 2. Commander checks command+flags only; core schemas validate values. Guard built as its own tsdown entry+bin so it never loads the 19 commands. — human.
- **T3 json.** Chose **uniform envelope**. `--json` → exactly one JSON doc on stdout for every outcome incl. crashes (`code INTERNAL`); logs/progress → stderr. `error.code` from one fixed core list; exit code looked up from that code in one table, never set separately. Contract test runs each command with `--json` against the envelope schema. — human.
- **T4 source.** Offered Zod-first / JSON-Schema-first / TypeBox. Chose **Zod-first (Zod 4, pinned)**: dates as strings (`z.iso.date()`/`z.iso.datetime()`, never `z.date()`); frontmatter = strict discriminated union on `type`; additive-only evolution (new fields optional, old deprecated never removed) from switch-over, with one migration pass for the bootstrap docs first. — human.
- **T4 json-schema role.** Chose **generated & contract-tested**. Commit generated files under `schemas/` + a check that fails on drift from a fresh export; `unrepresentable:"throw"`; Ajv devDep on `ajv/dist/2020`; `.refine()`s invisible in JSON Schema so Zod stays stricter — keep them rare and list each in ADR-004. — human.
- **T5 parser.** Chose **`yaml` (eemeli) + tiny splitter**. gray-matter rejected for date coercion (js-yaml 1.1) and `eval` of `---js` frontmatter (SEC-008). Explicit opts `version:'1.2', schema:'core', uniqueKeys:true, strict:true`; splitter strips BOM, CRLF→LF, `---` only at file start; `.gitattributes eol=lf`; in-place `parseDocument` edits keep key order/comments; `version` is an integer. — human.
- **T5 headings.** Chose **line scan skipping fences**. ATX only (≤3 spaces); fences `~~~`/` ``` ` close with same char ≥ length; exact text at exact level. Required headings per doc type in one registry beside the Zod schema; a section with only whitespace/HTML comments counts empty and fails, so untouched templates fail. — human.
- **T5 id index.** Chose **rebuild per command**. Scan explicit `project/` roots only (never `code/`); code-unit sort (not localeCompare); dup id = error; frontmatter refs only; dangling = warning on drafts, blocks at gates. `graph.json` = write-only output for sync/export, never read for decisions; guard never builds the index. — human.
- **T6 event id.** Chose **monotonic `seq`**: seq = line position (gap/dup = hard stop, like interior corruption); event types additive-only (reducer replays any old log); `actor` set by spine from shell detection, never a flag; `graph.json` has no generated-at timestamp (REQ-010); torn-line repair is human-only; one-machine assumption, cross-machine writes surface as git conflicts. — human.
- **T6 integrity.** Chose **per-record hash + git**, flagging that "only spine writes" isn't enforced yet. ADR-006 adds human-applied settings at switch-over: sandbox `denyWrite` + Edit/Write denies for the event-log dir, STATE.md, `project/.git`; `excludedCommands:["spine *"]`; human-only subcommand Bash denies (Topic 12); `allowUnsandboxedCommands:false`; spine runs outside the sandbox (never spawns project code; tests/builds stay sandboxed, Topic 11). Records hashed as raw bytes at submit, never edited even by spine; status lives in the log; every gate re-checks all record hashes. — human.
- **T6 locking.** Chose **hand-rolled `O_EXCL`**. Hold the lock only around read→validate→append→write graph→commit, never during slow work; re-read last seq under the lock; stale = pid dead on this host (`process.kill(pid,0)`); timestamp only for the error message (no time-expiry, which could steal a live lock); `proper-lockfile` targets long-running mtime-refreshing holders we don't have. — human.
- **T7 representation.** Chose **typed tables + generic reducer**. Tests cover the full state×event product (all refusals); guards are named pure fns (printable tables); docs diagrams generated from tables; a limit trip appends an explicit event (`task_blocked`); the reducer never infers a change without an event. — human.
- **T7 gates.** Chose **tags in code, config scopes (never disables)** by track/profile (`schema_migration` only for DB profiles). `spine.yaml` write-protected like the event log. Approval bound to the hash of what was approved (plan/CR/record) → doc change reopens the gate. `phase_pr` records PR#, base branch, merge SHA; a PR closed unmerged never satisfies it. — human.
- **T7 stages.** Chose **config-driven from `track.stages`** with the six stages/order fixed in code (track may omit; never reorder/add; spine validates). Track + gate set + limits copied into the increment-creation event; reducer reads them from there, not live `spine.yaml`, so editing config can't change old replays (REQ-010). Test: replay, edit `spine.yaml`, replay → identical. Config changes apply to new increments; running-increment track change via CR. — human.
- **T8 output.** Chose **A, path list**. Entries carry reason + bytes; in-doc ids (REQ/SEC/AC headings) indexed with **line ranges** so the role reads a slice (Read offset/limit), not the whole file — extends the ADR-005 index. `trusted:false` on client docs (SEC-008). "Latest verify" = highest attempt in the **event log**, not mtime. The list is read-first, not the read-scope (guard owns scope, Topic 10). The attempt-start event records the list + content hashes for reproducibility. — human.
- **T8 size.** Chose **soft warning** returned in `data` (envelope has no warnings field); budget counts **slices not whole files**; start ~100 KB (~25k tokens), tune from real tasks. **Also check at plan time**: `plan apply` computes each task's context size and lists over-budget tasks in the plan gate summary so they can be split before work; run-time stays a warning. — human.
- **T9 git access.** Chose **shell out to real `git`** (arg arrays). Runs outside the sandbox so must never execute working-tree code: `-c core.hooksPath=/dev/null -c core.fsmonitor=false` on every call. `code/.git` gets `denyWrite` from switch-over (blocks `git -C code` tricks); agents get read-only git + `GIT_OPTIONAL_LOCKS=0`. Stage explicit scope paths only (never `add -A`; out-of-scope → submit refuses). `LC_ALL=C`, `GIT_TERMINAL_PROMPT=0`, parse porcelain/`-z`. Trailers via `--trailer`; `project/` commits add `Spine-Seq:<n>` to cross-check with the log. git ≥2.32 at startup (else exit 3). — human.
- **T9 pr.** Chose **`gh` CLI**. Internal spine-run git/gh bypass the `gh`/push ask rules (rules only see `spine …`), so **`spine pr` goes in `ask`**; read-only status stays allowed. Push phase branches only, never `--force`. **Merge-commit only** (disable squash+rebase on repo create) so per-task trailers survive (REQ-042). **`phase_pr`** counts only if the PR head SHA equals the review-approved SHA and is an ancestor of base (`git merge-base --is-ancestor`), rejecting squash merges and post-review pushes. — human.
- **T10 active scope.** Chose **`active.json`**, with role from the hook input **`agent_type`** (one global hook, not per-agent `--role`; no agent_type = main session; unknown types read-only). Spine writes `active.json` **inside the ADR-006 lock** with the event seq (no drift). **realpath** scope matching; every tool matched, unrecognised tools **denied for scoped roles**. — human.
- **T10 bash.** Chose **targeted tokenizer** as a **per-role allowlist of shapes** (not a denylist): scoped roles get their check commands + read-only tools only; deny `$(…)`/backticks/`eval`/`-c`/`-e`/file-redirection/unparseable; writes only via Edit/Write (else `echo >file` bypasses scope). A **tripwire** — real controls are the sandbox + submit-time scope diff (ADR-009) + test-file hashes at "Tests ready" (catch tests rewritten during `pnpm test`). — human.
- **T10 fail mode.** Chose **fail closed**. CC blocks only on **exit 2**, so hook = `spine-guard || exit 2`; guard enforces its own short deadline (exit 2), never spawns processes, treats `tool_input` as untrusted (hooks run unsandboxed). No off switch (roll back to previous tarball); also **deny Edit/Write on `~/.claude/**`** so `disableAllHooks` can't be slipped into user settings. — human.
- **T11 containment.** Chose **spine wraps each check in the OS sandbox via `@anthropic-ai/sandbox-runtime`** (pinned, Apache-2.0, CC's sandbox; no hand-written profiles; missing Linux deps → exit 3). Network deny-by-default, per-check domain allowlist from the profile (Sanity host, `next/font/google`). Least-privilege secrets per check (`test` none; `build` only CMS token). Post-check sweep of changed+untracked files (incl. build output) for exact injected values → hit fails the check. Test: a sandboxed check can't read the keychain. — human.
- **T11 command form.** Chose **argv arrays calling tools directly** (`pnpm exec vitest run`/`eslint .`/`tsc --noEmit`), never package.json scripts (coder could set `test` to `exit 0`). Check configs (package.json, lockfile, vitest/eslint/tsconfig) default-forbidden to coders (change via plan/CR). Vitest JSON reporter → checks.json records passing tests; submit requires a passing `AC-n` test per acceptance criterion (skips don't count). — human.
- **T11 redaction.** Chose **exact-value redaction** + base64 + URL-encoded forms; redact full captured output before summarising (chunk-split safe); refuse secret values <8 chars at setup. Keychain via `security`/`secret-tool`; WSL-without-Secret-Service → 0600 file outside workspace + Read deny + sandbox denyRead; Bash-deny `security`/`secret-tool` for agents. — human.
- **T12 detection.** Rejected env-var/TTY (not boundaries: VS Code sets `CLAUDECODE=1` in the human's terminal; `script` fakes a TTY). Chose **OS-enforced**: human-only cmds in a separate **`spine-admin`** binary **not** in `excludedCommands`, so an agent running it is sandboxed and `denyWrite` blocks it; human runs it outside CC. Main `spine` has no admin code; Bash-deny `spine-admin *`; y/N + hash shown as UX only. — human.
