## Summary

AC-1, AC-2, AC-4 and AC-5 all pass on clean machine-readable evidence. AC-3 is rejected: the curl call ended with "Interrupted · What should Claude do instead?" rather than a captured network-denial error, leaving the deny mechanism unconfirmed. Because AC-3 is a hard requirement for ADR-010's D2 guard, the task does not pass on this attempt.
