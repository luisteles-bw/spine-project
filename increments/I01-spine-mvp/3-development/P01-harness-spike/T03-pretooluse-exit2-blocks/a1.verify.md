code" and running the command (AC-2), and treats a missing `spine-guard` binary as a blocking

arm (AC-3). This confirms ADR-010's fail-closed design is enforced by the runtime; the wrapper is
mandatory, not optional. Both sessions were run under the hardened posture (`--permission-mode
default`, `disableAutoMode: "disable"`, no auto-mode override), making T03 the first clean probe
under that posture following the F-1 fix.
